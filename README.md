🛍️ Amazon Diwali Sales Dashboard – Power BI

📌 Project Overview

This project presents an interactive Amazon Diwali Sales Dashboard created using Microsoft Power BI. It analyzes sales performance, product categories, payment methods, delivery status, and geographical distribution.

📊 Dashboard Highlights

- Total Sales: ₹111.82 Crores
- Total Quantity Sold: 44.77K
- Year: 2025
- Product Category Analysis
- Payment Method Analysis
- State-wise Analysis
- Delivery Status Analysis

🔍 Key Insights

- Total sales reached ₹111.82 Crores.
- Total quantity sold was 44.77K.
- Delivered orders accounted for 33.83%.
- Pending orders accounted for 33.63%.
- Returned orders accounted for 32.54%.
- Sales and product categories are analyzed through interactive visuals.
